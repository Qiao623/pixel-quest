🕹️ 操作說明

單人模式

  • 移動：A / D 或 ← / →
  • 跳躍：W / ↑ / 空白鍵
  • 暫停：Esc

雙人模式

  • 玩家 1：A / D 移動，W 跳躍
  • 玩家 2：← / → 移動，↑ 跳躍
  • 兩位玩家都要抵達出口才能過關。

  • 🚪 抵達出口，選擇是否挑戰下一關。
